# CS5185 系统设计与代码分工

| 成员               | 设计与实现职责                                                                                                                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 陈柏政（72510800） | **总体架构与策略设计。** 定义 CLI、TUI 和批量实验共用的单任务流程，确定各模块的输入输出、尝试上限和停止条件。设计固定基线、冻结规则与 Ark 决策的调用方式，确定如何用开发集校准规则，以及如何校验策略返回的 preset 和 AQ。 |
| 吴柏青（72610405） | **码率控制与编码执行。** 将 5% 和 2% 的文件大小预算换算为初始码率，把策略选定的 preset 和 AQ 转成 FFmpeg/libx264 双遍编码参数。记录实际输出大小、编码耗时与错误；输出超限时计算下一次尝试的码率。                         |
| 朱浩阳（72610190） | **内容特征与质量评价。** 从输入视频提取帧间差和边缘密度，向策略模块提供数值摘要。编码后核对输入输出的分辨率、帧数、帧率和时间戳，再计算原分辨率亮度平面的 PSNR 与 MS-SSIM。                                               |
| 陈昊（72611033）   | **用户界面与实验运行。** 将命令行和英文 TUI 接入共用任务流程，处理任务配置、进度、取消与结果查看。组织批量对照实验，按视频、预算和策略汇总任务记录并导出图表。                                                            |

以一次 2% 预算任务为例，陈昊负责从界面或批量入口提交任务。陈柏政负责的任务流程读取朱浩阳模块生成的特征摘要，调用策略选出 preset 和 AQ，再调用吴柏青的编码模块执行双遍编码。若输出超限，编码模块计算新码率，由任务流程判断是否继续；达标后，评价模块检查完整性并计算画质指标，界面与实验模块读取结果用于展示和汇总。
